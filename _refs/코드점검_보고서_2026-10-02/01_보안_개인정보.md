# 1. 보안·개인정보

## A1. CSP 헤더가 실제로 적용되지 않음 🔴 {#a1}

**문제**: 루트에 설정 파일이 두 개 있다.

- `next.config.mjs` — 내용이 `export {};` 뿐 (주석: "next.config.ts를 사용합니다")
- `next.config.ts` — `/calculator`·`/settings` CSP 헤더, `serverExternalPackages` 설정

Next는 `next.config.js → .mjs → .ts` 순서로 **처음 찾은 파일 하나만** 읽는다
(`node_modules/next/dist/shared/lib/constants.js:359` `CONFIG_FILES`). 그래서 빈 `.mjs`가 채택되고
`.ts`는 무시된다.

**확인한 근거**: `.next/dev/routes-manifest.json`의 `headers`가 `[]` — CSP가 하나도 등록돼 있지 않음.
Vercel 배포본도 같은 규칙이라 같은 상태일 것으로 보인다(배포 응답 헤더로 최종 확인 권장:
`curl -I https://<배포주소>/calculator`에 `Content-Security-Policy`가 있는지).

**영향**: CLAUDE.md "개인정보 보호 원칙"이 꼽은 장치 셋 중 하나(브라우저가 외부 전송을 막는 CSP)가 꺼져 있다.
지금은 정적 스캔(F2)만 남아 있는 상태.

**수정안**: `next.config.mjs` 삭제(이 파일은 `68587a2` 초기 구조 커밋 때 생긴 잔재). 삭제 후
`next dev` 재시작 → `/calculator` 응답 헤더에 CSP가 붙는지 확인. 
⚠️ CSP가 처음으로 실제 적용되는 거라, 계산기·설정 페이지에서 폰트(jsdelivr)·PDF 뷰어(`public/docs/인사계획.pdf`)·
주소 검색(`/api/geocode`)이 정상 동작하는지 같이 확인할 것. 막히는 게 있으면 콘솔에 CSP 위반이 찍힌다.

## A2. 실제 인사기록카드 예시가 git에 커밋됨 🔴 {#a2}

**문제**: `_refs/인사기록0.xlsx`~`인사기록3.xlsx`가 추적 중이고 원격(`github.com/JSM000/newBase`)에 올라가 있다.
CLAUDE.md는 이 파일들을 "실제 NEIS 인사기록카드 예시"라고 설명한다. 열어보면 학교명·발령 이력과 함께
**질병휴직·육아휴직 기록**, 연수 강사 이름 등이 들어 있다.

**확인 필요**: (1) 레포가 공개인지, (2) 파일이 실제 인물 자료인지 가공 자료인지.

**수정안 (실제 자료라면)**:
1. 레포가 공개면 우선 비공개로 전환.
2. 파일을 git에서 빼고(`git rm --cached`) `.gitignore`에 추가, 로컬에만 둔다.
3. 히스토리에서도 지우려면 `git filter-repo` 등으로 재작성 + 강제 푸시가 필요 — 협업자·포크가 있으면
   영향이 크니 별도로 판단.
4. 테스트용 고정 자료(F1)가 필요하면 이름·학교를 바꾼 가공 파일을 새로 만들어 쓰는 걸 권장.

## A3. 소셜 RPC(별점·조회수·즐겨찾기) 남용 여지 🟡

`supabase/migrations/0001_school_social.sql` 등 — 로그인 없이 `anon`이 RPC를 바로 호출하는 구조라
알려진 한계지만 기록해 둔다.

- `rate_school`: `p_client_id`를 클라이언트가 정하므로 UUID만 바꾸면 한 사람이 무제한 투표 가능.
- `bump_school_view`: 호출 횟수 제한이 없어 조회수 부풀리기 가능.
- 둘 다 `p_school_code`를 검증하지 않아 **존재하지 않는 학교 코드로 행을 무한히 만들 수 있음**
  (테이블이 계속 커짐).

**수정안(가벼운 순)**: RPC 안에서 `p_school_code`를 정규식(`^[A-Z0-9]{10}$` 등 실제 형식)이나 학교 목록 테이블로
검증 → 쓰레기 행은 막힌다. 투표 조작은 로그인 없이는 근본 해결이 어려우니 지금 범위에서는 "참고용 수치"라는
UI 문구 정도로 충분할 수 있음.

## A4. 지도 툴팁에 학교명을 이스케이프 없이 HTML로 넣음 🟡

`src/components/kakao-map/kakao-map.tsx:499-503` — `tooltip.setContent(\`...${school.schulNm}...\`)`.
학교명은 빌드 스크립트가 학교알리미에서 받은 자료라 지금 당장 위험은 낮지만, 데이터 원천이 바뀌면
XSS 통로가 된다. `textContent`로 DOM을 만들거나 간단한 escape 함수를 거치게 하면 끝.
