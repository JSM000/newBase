# 코드 점검 보고서 (2026-10-02, main 기준)

프로젝트 전체를 읽고 "고쳐야 할 것 / 최적화할 것"을 정리한 보고서. **코드는 하나도 바꾸지 않았다** —
항목별로 검토 후 적용 여부를 정하면 된다.

검증 방법: 코드 정독 + 읽기 전용 확인(빌드 산출물 manifest 확인, 점수 계산 코드를 임시 폴더로 변환해
`_refs/인사기록0~3.xlsx`에 돌려봄). `npm run build`·`tsc`·`lint`는 돌리지 않았다(샌드박스가 `npx` 차단).
