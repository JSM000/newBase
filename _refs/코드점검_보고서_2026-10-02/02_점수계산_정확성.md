# 2. 점수 계산 정확성 (`src/lib/score-calculator.ts`)

## 샘플 4건 실행 결과

점수 계산·엑셀 파싱 코드를 임시 폴더에서 JS로 변환해 `_refs/인사기록0~3.xlsx`에 그대로 돌린 결과
(가산점·체육 등 수동 입력은 전부 '없음'):

| 파일 | 원시 경력 개월(`careerMonths`) | 경력점 | 현임교 / 부임일 | 현임교 개월 |
|---|---|---|---|---|
| 0 | **120** | 60 | 산성초 / 2023-03-01 | 36 |
| 1 | **96** | 60 | 율봉유치원 / 2025-03-01 | 12 |
| 2 | **120** | 60 | 상당초 / 2024-09-01 | 18 |
| 3 | **121** | 60 | 봉명초 / 2020-03-01 | 60 |

5년(60개월) 창 안에서 원시 개월 수가 60을 넘을 수 없는데 96~121이 나온다 → 아래 B1.

## B1. 경력 개월 중복 합산 + 휴직 미제외 🔴 {#b1}

**위치**: `score-calculator.ts:126-153`

**문제 1 — 중복 합산**: NEIS 경력 행은 "기간"이 아니라 "발령 이벤트" 단위라 같은 기간에 여러 행이 겹친다.
예) 인사기록3:

```
2020.03.01 ~          | 교육청내전보   | 봉명초   ← 끝 날짜 없음 → 기준일까지 60개월
2021.03.01 ~ 2022.02.28 | 담임교사     | 봉명초   ← 위와 겹침
2022.03.01 ~ 2023.02.28 | 담임교사     | 봉명초   ← 위와 겹침
2023.05.30 ~ 2024.02.29 | 1호:질병휴직 | 봉명초   ← 위와 겹침
...
```

코드는 학교명에 '초등학교/유치원'이 있는 행을 **전부 더한다**. 지금은 `Math.min(careerMonths, 60)` 때문에
결과가 항상 60점으로 "맞아 보이지만", 실제로는 근무 기간과 상관없이 누구나 만점이 된다.

**문제 2 — 휴직 미제외**: 인사기록3은 2021.10.18~11.19, 2023.05.30~2025.05.29 질병휴직(합계 약 25개월)이
있다. 기준(`_refs/관외전보_점수계산_유초등.md` 2-2, 인사관리기준 제11조)상 일반 휴직은 경력점 불인정인데
파서·계산기 어디에도 휴직·파견 처리가 없다. 이 사람은 60점이 아니라 약 35점이어야 할 가능성이 높다.

**수정안**:
1. 경력 행을 **구간(interval)으로 바꿔 병합**한 뒤 개월을 센다 (겹치는 구간은 한 번만).
2. `appointmentType`에 `휴직`이 들어간 행(`1호:질병휴직`, `7호:육아휴직`, `휴직연장` 등)을 "불인정 구간"으로
   모아 병합된 근무 구간에서 **빼고** 센다. `휴직복직` 행은 하루짜리 표식이라 무시.
3. 육아휴직(1년 미만 인정/이상 불인정, 연장 합산), 공무상 질병휴직, 파견 종류별 예외는 2-2·2-3 표대로
   분기. 인사기록카드만으로 판단이 안 되는 건(공무상 여부 등) 사용자 확인 입력으로.
4. 지역가산점(`regionalBonusMonths`)도 같은 "인정 구간"을 써야 한다(지금은 부임일~기준일 전체).

## B2. 교과전담 실적: 2022.3.1. 전/후 규칙이 반대 🔴 {#b2}

**위치**: `score-calculator.ts:293-294`

```ts
const cutoff = new Date('2022-02-28');
const validStart = start > cutoff ? start : (s.isAdminTeam ? start : null);
```

현재 동작: 2022.3.1. **이후**는 무조건 인정, **이전**은 교무행정지원팀일 때만 인정.

기준(`관외전보_점수계산_유초등.md` 4-6, 인사관리기준 26.7.29본 부칙 3항): 교무행정지원팀 한정은
**2022.3.1. 이후 실적부터** 적용, 2022.2.28.까지는 팀 여부와 무관하게 **모두 인정**. → 정확히 반대다.

샘플 4건엔 "2022.3 이후 + 팀 아님" 행이 없어 결과 차이는 안 보였지만, 일반 교과전담 교사는 부당하게
점수를 받게 된다.

**수정안**: 구간을 2022.2.28. 기준으로 쪼개서 앞부분은 무조건 인정, 뒷부분은 `isAdminTeam`일 때만 인정.
(지금처럼 시작일 하나로 통째로 판단하면, 2021.3~2022.2 같이 경계를 걸친 행 처리도 틀어진다.)

## B3. 경력점이 "현임교"가 아니라 5년 내 모든 학교 기준 🟠 {#b3}

**위치**: `score-calculator.ts:145-152`

기준 문구는 "**현임교(원) 경력** 최근 5년간을 1월 1점"(인사관리기준 제11조 3항, 참고 md 2-1).
코드는 5년 창 안의 **모든 초등·유치원 경력**을 더한다. 샘플 0(현임교 36개월), 2(18개월)도 60점이 나온다.

**확인 필요**: 관외전보에서 경력점을 정말 현임교 기준으로만 매기는지(청주 관내 기준과 관외 기준이 다를 수
있음). 현임교 기준이 맞다면 `careerMonths`를 현임교 인정 구간(B1 수정 후)으로만 계산하면 된다.

## B4. 직무연수 학년도 끝이 2월 28일 고정 → 윤년 누락 🟠 {#b4}

**위치**: `score-calculator.ts:260-261`

```ts
const syEnd = new Date(`${sy + 1}-02-28`);
```

2023학년도는 2024.2.29.까지인데 끝을 2.28.로 잘라서, **2024.2.29.에 끝난 연수는 어느 학년도에도 안 들어간다**.
(샘플 3의 담임 행도 `2023.03.01 ~ 2024.02.29`라 실제로 이런 날짜가 나온다.)

**수정안**: `syEnd = new Date(\`${sy + 1}-03-01\`)` 로 두고 `endD < syEnd`(미만)로 비교.

## B5. 기타 규칙 확인 사항 🟡 {#b5}

- **휴직 중 실적점**: 담임 행(`2023.03.01~2024.02.29`)이 같은 기간 질병휴직과 겹쳐도 담임 실적이 12개월
  그대로 인정된다. 기준상 휴직 기간은 실적점도 불인정(육아휴직 예외 있음) → B1의 "불인정 구간"을 담임·부장·
  교과전담·특수통합·복식 계산에도 똑같이 빼야 한다.
- **부장 vs 교과전담 중복**(`:327-341`): 기준은 "**동일 기간** 중복 시 유리한 것 하나"인데 코드는 전체 총점을
  비교해 한쪽을 통째로 버린다. 서로 다른 해에 각각 했으면 둘 다 받아야 한다 → 월 단위로 겹치는 달만 비교.
- **현임교 부임일**(`:140`): `find(c => c.school === lastSchool)`라서, 예전에 같은 학교에 근무하다 떠났다
  돌아온 경우 **옛 부임일**을 잡는다(학교만기 판단 `transfer-eligibility.ts`도 이 값을 씀). 마지막 연속 구간의
  시작일을 쓰는 게 맞다.
- **포상·연구실적 "1년"의 단위**(`:169`, `:215`): 달력 연도(`date.substring(0,4)`)로 묶는다. 다른 항목은
  학년도(3월~2월) 기준이라 원문이 어느 쪽인지 확인 권장.
- **개월 반올림**(`countMonths`): 행마다 "15일 이상이면 1개월"을 적용한 뒤 합산한다. 짧은 구간이 여러 개면
  합산 후 한 번 반올림한 값과 달라질 수 있다 — B1에서 구간을 병합하면 자연히 해결.
