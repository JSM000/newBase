# 3. 관심학교 목록 한눈에 보기 — ⚠️ 부분 구현 (가벼운 조회 모달만, `/settings`)

`/statistics`에서 둘러보는 중의 목록 화면(필터 연동, 지도 이동, 비교)은 여전히 **2차로
연기** — 학교 비교 탭 몫이다. 다만 "내 관심학교가 뭐였는지 그냥 보고 싶다"는 수요가
있어서, **`/settings` 페이지에 조회 전용 모달**을 먼저 넣었다(`settings-container.tsx`의
`favoritesListOpen`) — 학교명·학교급·시군만 나열, 클릭해도 아무 데도 안 가고, 개별
삭제도 없음. 상세: [05_보존정책.md](05_보존정책.md)의 "`/settings` 페이지 연동" 절.

**아직 없는 것(학교 비교 탭 몫)**: 지도·필터와 연동되는 목록, 목록에서 항목 클릭 시
상세 이동/지도 포커스, 목록 안에서 개별 삭제, 여러 학교 통계 나란히 비교. "관심학교를
한 화면에 모아 본다"는 요구 자체가 사실상 **학교 비교 탭**이 하려는 일과 거의 같다 —
비교 탭도 결국 관심학교 목록을 불러와 각 학교 카드를 나란히 놓는 화면이 될 것이므로,
그 목록 UI(필터 연동 포함)를 여기서 먼저 만들고 비교 탭에서 또 만드는 중복을 피한다.

학교 비교 탭 자체의 설계(레이아웃, 비교 항목 선정, 최대 비교 개수 등)는 별도 계획
문서([`_refs/학교비교_구현계획/00_개요.md`](../학교비교_구현계획/00_개요.md))에서 다룬다 — ✅ 구현 완료.

## 아래는 그때 참고할 초안 메모 (지금 구현 대상 아님)

- 진입 지점: 필터 바 또는 별도 버튼으로 "관심학교 (N)" 노출 → 클릭 시 비교 탭/패널 오픈.
- 정렬: 추가한 순서(스토어 `favoriteCodes` 배열 순서, 최근 추가가 위로) 또는 학교명
  가나다순 — 후자가 다시 찾기 쉬워 보이지만 미확정.
- 각 항목에 "관심학교 해제" 버튼 — 목록에서 바로 제거([05_보존정책.md](05_보존정책.md)의
  "개별 삭제"가 여기 해당).
- 빈 상태 안내 문구: "아직 관심학교가 없어요…" 류.
- 목록에서 학교를 고르면 상세 패널 전환 + 지도 이동 — 이때 그 학교가 현재 시·군/학교급
  필터에 안 걸려 지도의 `filtered` 배열에 없을 수 있음(필터 무관하게 전체 관심학교를
  보여주는 화면이므로). 상세 정보 확인 자체는 문제없지만 지도 마커가 안 보일 수 있다는
  점은 비교 탭 설계 시 다시 검토.
