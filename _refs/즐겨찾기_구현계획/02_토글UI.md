# 2. 관심학교 토글·표시 UI

> **업데이트(구현 완료 후)**: 아래 본문은 설계 당시(별 모양) 그대로 남겨두고, 실제
> 구현은 **하트 모양 + red-600(#dc2626, primary #e77474와 같은 붉은 계열이되 더 진하고
> 순수한 빨강)**으로 바꿨다 — 별점(school-rating.tsx, 1~5점)과 모양이 겹친다는 지적
> + 처음 넣었던 pink-500이 "색이 이상하다"는 피드백으로 재조정. `lucide-react`의 `Star`
> 대신 `Heart`, `fill-amber-400 text-amber-400` 대신 `fill-red-600 text-red-600`. 지도
> 마커 배지(D)도 흰 원 + 빨간 하트로, 툴팁(E)의 `★` 접두어도 빨간 `♥`로 바꿨다.
> 또한 이 토글에 **서버 집계 동기화**가 추가됨 — 아래 "1차 범위" 설명과 별개로,
> `useSyncFavorite`(`use-school-social.ts`)가 Supabase에 관심학교 등록/해제를 반영해
> "관심학교 등록 수"를 별점·조회수처럼 지도 색칠/순위 지표로 쓸 수 있게 됨. 상세는
> [00_개요.md](00_개요.md)의 "서버 집계 확장" 절 참고.
>
> **용어**: "즐겨찾기"라는 말 대신 **"관심학교"**로 통일했다(스위치 라벨을 4글자의
> 명확한 단어로 바꾸면서). 아래 본문에 남아있는 "즐겨찾기"는 설계 당시 표현 그대로다 —
> 코드 식별자(`toggleFavorite`, `isFavorite`, `favorite` 파라미터 등)는 안 바꿨다.

1차 범위는 다섯 곳 — **토글 가능**(눌러서 추가/해제) 세 곳 + **표시 전용**(누르면 상세로
안 가고 그냥 하트만 보임) 두 곳. "표시 전용"으로 둔 이유는 각 위치의 상호작용 설계 참고.

## 토글 가능한 곳 (3곳)

**A. 상세 패널 헤더** (`school-detail-panel.tsx:355~388`)

학교명 옆에 "신설" 뱃지, 닫기(X) 버튼이 오른쪽 끝. 하트 아이콘 버튼을 닫기 버튼 왼쪽에
추가한다(`lucide-react`의 `Heart` — 이미 `Eye`/`X` 등 같은 패키지 아이콘을 쓰고 있어 새
의존성 불필요). 관심학교면 채운 하트(`fill="currentColor"`) + red-600 계열 색, 아니면
외곽선만.

**B. 순위 목록 각 행** (`school-ranking-panel.tsx:160~191`)

`<li>`의 버튼이 행 전체 클릭 영역(상세 이동)이라, 하트 아이콘을 행 오른쪽(순위 값 표시
칸 옆)에 별도 버튼으로 추가하고 `onClick`에 `e.stopPropagation()`을 걸어 행 클릭과
분리한다.

**C. 길찾기 결과 목록 각 행** (`commute-panel.tsx:143~190` 근방, `ordered.map`)

B와 완전히 동일한 구조 — 각 결과도 행 전체가 버튼(`onSelectCode` 호출)이라, 소요시간
표시 칸 옆에 하트 아이콘을 `stopPropagation`과 함께 추가.

공용 패턴(세 곳 다 동일, 실제로는 `favorite-toggle-button.tsx`로 공용 컴포넌트화함):

```tsx
<button
  type="button"
  onClick={(e) => {
    e.stopPropagation(); // 목록 행에서만 필요, 상세 패널 헤더는 불필요
    toggleFavorite(schulCode);
  }}
  aria-label={isFavorite(schulCode) ? '관심학교 해제' : '관심학교 등록'}
>
  <Heart className={isFavorite(schulCode) ? 'fill-red-600 text-red-600' : 'text-zinc-300'} />
</button>
```

## 표시 전용인 곳 (2곳) — 마커·툴팁

사용자 요청으로 추가: "마커, 상세페이지 이외에 어디에서 관심학교를 표시할 수
있을까?"에 대한 답으로 지도 위 두 곳을 포함한다. 둘 다 클릭하면 기존 동작(학교 선택)이
그대로 실행돼야 하므로 하트 자체에 별도 onClick을 걸지 않는다(눌러서 토글하고 싶으면
상세 패널을 열어서 A로 하면 됨) — 지도에서 즉시 토글까지 넣으면 실수로 지도 클릭 한 번에
토글돼버릴 위험이 있어 1차에서는 "표시만".

**D. 지도 개별 마커** (`marker-image.ts`, `kakao-map.tsx:456~461`)

개별 마커 tier(줌인 상태)에서만 의미가 있다 — 클러스터 tier는 여러 학교를 뭉친
상태라 관심학교 여부를 마커 하나에 표시할 수 없다. `getMarkerImage()`가 만드는 SVG
핀(`marker-image.ts:46~65` `svgPin()`)에 `favorite: boolean` 파라미터를 추가해서,
true면 핀 머리 오른쪽 위 모서리에 작은 하트 아이콘(흰 원 배경 + 빨간 하트, 지름 대략
핀 머리의 40%)을 겹쳐 그린다. 캐시 키(`marker-image.ts:75`)에도 `favorite` 여부를
포함시켜야 한다(`${color}|${selected}|${scale}|${favorite}`) — 안 그러면 관심학교와
아닌 학교가 같은 이미지를 공유해버림.

`kakao-map.tsx`의 개별 마커 렌더 루프(445~462행)에서 `isFavorite(school.schulCode)`를
계산해 `getMarkerImage(...)` 호출에 새 인자로 넘긴다. 이 루프의 `useEffect` 의존성
배열(505행)에도 관심학교 상태가 바뀌면 다시 그리도록 값을 추가해야 한다 — 스토어를
zustand로 구독하면(1_저장방식) 자동으로 리렌더 트리거됨.

**E. 지도 마커 호버 툴팁** (`kakao-map.tsx:484~489`)

툴팁 콘텐츠(`<b>${school.schulNm}</b> ...`) 앞에 관심학교면 빨간 `♥ ` 접두어만 붙인다
— D와 세트로 저비용 추가(같은 mouseover 핸들러 안, 이미 school 객체를 들고 있음).

## 별점(rating) 위젯과의 구분

기존 "내 평가" 별점(`school-rating.tsx`)은 1~5점 평가라 별 5개를 늘어놓는 완전히 다른
UI다. 관심학교는 on/off 하나뿐이라 하트 1개만 쓴다 — 모양(별 vs 하트)과 색(amber vs
red-600) 둘 다 달라서 시각적으로 헷갈리지 않는다. 위치도 떨어뜨린다(별점 위젯은 본문
안에 카드로, 관심학교 토글은 헤더 우측 상단).

## 2차로 미루는 추가 표시 위치 후보 (참고만)

- 지도 클러스터 뱃지(시·군/읍면동 단위 뭉친 원)에 "관심학교 N개 포함" 표시 — 뭉친
  상태라 우선순위 낮음, 필요해지면 추가.
- 필터 바 자체에 상시 "관심학교 N" 카운터 — 목록 진입점([03_목록보기.md](03_목록보기.md))과
  같이 2차(학교비교 탭)에서 정리.
