# 학구도 지도 기능 구현 계획

> 목표: 지도에서 **학교 마커를 클릭하면 그 학교의 학구(통학구역)를 색칠**해서 보여준다.
> 공동통학구역은 전용 통학구역과 **다른 스타일로 구분** 표시.
> 데이터 소스: 한국교육시설안전원 학구도 공공데이터(schoolzone.emac.kr, 2026-03-20 기준)

---

## 1. 범위

- **지역**: 충청북도 전역 (지도 통계 기능과 동일 범위)
- **학교급**: 초 · 중 · 고 (유치원은 학구도 데이터 자체가 없음)
- 점수 계산 기능(청주·유초등)과는 **별개**

---

## 2. 학구 데이터의 성격 (개발 전 알아야 할 것)

### 초등 · 중학교 — 학구가 촘촘함
- 학교 1곳 ↔ 학구 N개 (다대다). 연계정보 CSV로 매핑.
- 각 학구는 `HAKGUDO_GB` 로 구분:
  - `0` = **전용** 통학구역 / 중학구
  - `1` = **공동** 통학구역 / 공동학구 (`~초~초공동통학구역` 식으로 여러 학교가 공유)
- `공동(일방)통학구역` = 한쪽 방향 배정만 허용. 별도 필드 없이 이름에 "일방" 포함으로만 구분.
- 전용 구역과 공동 구역은 지리적으로 **겹침** → 렌더 순서·투명도 주의 (공동은 테두리/빗금만 위에 얹는 편이 깔끔).
- 전용 구역이 없고 공동 구역만 있는 학교도 있음 (충북 초등 중 다수).

### 고등학교 — 학구 개념 없음, 권역만
- **평준화 3곳**만 별도 경계: `청주시고등학군`, `충주시고등학군`, `충북혁신도시고등학교군` (각 시 도심권, 시 행정구역보다 작음)
- 나머지 충북 전역 = `충청북도단일학교군`(비평준화) 폴리곤 1개 = 충북 전체에서 평준화 3곳을 hole로 도려낸 도넛
- 비평준화 고교는 연계 학구ID가 **없음** → 클릭 시 색칠할 학구가 없음 ("비평준화 지역, 지정 학구 없음" 안내 필요)
- 평준화 고교는 클릭 시 시 단위 학군 전체가 색칠됨 (배정학교 개념 아님)

## 3. 원본 데이터 (`_refs/학구도/`)

| 파일 | 형식 | 좌표계 | 인코딩 |
|---|---|---|---|
| 초등학교통학구역 / 중학교학교군 / 고등학교학교군 / 고등학교비평준화지역 / 교육행정구역 | SHP(폴리곤) | **EPSG:5186** (중부원점 TM) | DBF=CP949 |
| 초중등학교위치_20260320.csv | CSV | 위경도 WGS84 | **UTF-8 BOM** |
| 학교학구도연계정보_20260320.csv | CSV | — | **CP949** |

- SHP 폴리곤 속성엔 학교 정보 없음. 학교↔학구는 연계 CSV(`학구ID` ↔ `학교ID`), 학교 좌표는 위치 CSV.
- 코드: 충북 `SD_CD = '43'`, 시도교육청명 `충청북도교육청`.
- 조인 정합성 양호: 연계 CSV의 학구ID는 전부 SHP에 존재. SHP에만 있는 학구·위치 CSV에 없는 학교ID는 소수(폐교 등) → 예외처리.

## 4. 전처리 — 완료됨

**스크립트**: `scripts/build-school-zones.mjs` (의존성 없음, `node scripts/build-school-zones.mjs`)

처리 내용:
1. 충북만 필터 (`SD_CD === '43'`)
2. EPSG:5186 → WGS84 역투영 (TM 역변환식 직접 구현, proj4 불필요)
3. 링 분류(외곽/홀) → Polygon | MultiPolygon, GeoJSON RFC7946 winding 정규화
4. Douglas–Peucker 단순화(tolerance ≈ 20m) + 좌표 5자리 반올림

### 출력물 (`public/data/`)

| 파일 | 내용 | 건수 | 크기(gzip) |
|---|---|---|---|
| `chungbuk-school-zones-elementary.geojson` | 초등 통학구역/공동통학구역 | 351 | 941KB (245KB) |
| `chungbuk-school-zones-middle.geojson` | 중학구/공동학구 | 123 | 615KB (168KB) |
| `chungbuk-school-zones-high.geojson` | 고교 학교군(3)+비평준화(1) | 4 | 127KB (38KB) |
| `chungbuk-edu-districts.geojson` | 교육지원청 관할 경계 (배경용) | 10 | 89KB |
| `chungbuk-school-zone-links.json` | `{학교ID: {name, level, dedicated:[{zoneId,zoneName}], shared:[{zoneId,zoneName}]}}` | 434교 | 53KB |
| `chungbuk-school-zone-points.json` | 학교 마커 `[{schoolId, name, level, foundType, isBranch, eduName, address, lat, lng, hasZone}]` | 483 | 130KB |

**GeoJSON Feature.properties**: `zoneId`, `zoneName`, `zoneType`(elementary|middle|high_zone|high_nonpyeongjunhwa), `level`, `kind`(dedicated|shared), `oneWay`, `sggCode`, `eduCode`, `eduName`, `updatedAt`

동작: 학교 클릭 → `links[학교ID]` → `dedicated`/`shared` 학구ID 목록 → 해당 GeoJSON feature 필터해서 렌더.

## 5. 구현 현황 (2026-09-16)

**1차 구현 완료** — 기존 `/statistics` 통계 지도(카카오맵)에 레이어로 얹음(별도 페이지 안 만듦).

- **화면 흐름**: 지도에서 학교 마커 클릭 → 상세 패널 열림 → 그 학교의 학구가 지도에 색칠 + 패널에 학구명 목록 표시.
- **스타일**: 전용 구역 = 진한 파랑 실선 채움(`kakao-map.tsx` zIndex 2), 공동구역 = 옅은 주황 점선 테두리(zIndex 3, 전용 위에 겹쳐 그림). 상세 패널의 배지 색도 동일하게 맞춤.
- **stats 조인**: `src/lib/school-zone-match.ts` — 학교급+이름 정확 일치 우선, 실패 시 "학구도 이름이 학교통계 이름으로 끝나는지"(지역 접두어 케이스, 예: `청주대성초등학교` ⊇ `대성초등학교`)로 재시도, 동명 후보 여럿이면 좌표 최근접으로 확정. **실측 매칭률 92.4%**(524교 중 484교) — 나머지 7.6%는 학구도 원본 자체에 없는 학교(신설·통폐합 등 소스 간 시차 추정)라 매칭 실패 시 학구 섹션을 조용히 숨김(`zoneStatus: 'unmatched'`, 깨진 UI 노출 안 함).
- **lazy load**: 학구 GeoJSON은 학교급별 파일(초/중/고)이 따로 있고, 학교를 클릭해 그 학교급이 필요해질 때만 `useSchoolZones(level)`가 불러옴 — 세 파일을 한 번에 안 받음.
- **links.json에 zoneName 포함**: 전처리 스크립트가 학구ID뿐 아니라 이름도 같이 내보내(`{zoneId, zoneName}`), 상세 패널이 폴리곤 GeoJSON 로딩을 안 기다리고 바로 학구명을 보여줌.
- **고교**: 평준화 학군은 위와 동일하게 색칠(`dedicated`로 분류돼 있음), 비평준화는 매칭돼도 학구가 비어 있으므로 "비평준화 지역 — 별도로 지정된 학구가 없습니다" 안내만 표시.

**남은 것**:
- **단순화 강도**: 현재 20m(스크립트 상수 `SIMPLIFY_TOLERANCE`). 실제 화면에서 도심 소규모 학구가 뭉개져 보이면 조정.
- **경계 이음새**: 폴리곤별 독립 단순화라 인접 학구 사이 미세한 틈/겹침 가능 — 지금 기능(학교 1곳 클릭 → 그 학구만 그림)엔 거의 안 보임. 여러 학구를 동시에 빈틈없이 깔아야 하는 화면이 생기면 mapshaper로 topology 보존 재처리.
- **매칭 실패 7.6%**: 주소·좌표 기반 퍼지 매칭 등으로 더 끌어올릴 여지 있음(지금은 손 안 댐).
- 실제 화면 확인은 이 세션에서 못 함(샌드박스가 `next build`/`next dev`의 포트 바인딩을 막음) — `npm run dev`로 직접 확인 필요.
