# 충북 지역 선택 지도 구현 계획

## 목표

홈 화면에서 충청북도 시군구 지도를 SVG로 표시하고,
각 지역을 클릭해 현재 근무지를 선택할 수 있도록 한다.

---

## 구현 방식 비교

### 방식 A — 하드코딩 SVG (권장)

GeoJSON 경계 데이터를 Python 스크립트로 SVG path로 변환한 뒤,
React 컴포넌트에 하드코딩한다.

**장점**
- 추가 npm 패키지 불필요
- 런타임 외부 요청 없음 (빠름)
- 스타일/인터랙션 완전 제어 가능

**단점**
- GeoJSON → SVG 변환 작업 1회 필요

**구현 흐름**
```
GeoJSON 파일 준비
  → Python 변환 스크립트 실행 (내가 작성)
  → SVG path 데이터 생성
  → ChungbukMap.tsx 컴포넌트에 삽입
  → 클릭 핸들러 연결
```

---

### 방식 B — react-simple-maps 패키지

`react-simple-maps` 라이브러리가 GeoJSON을 읽어 SVG를 동적으로 렌더링한다.

**장점**
- 변환 작업 불필요 (GeoJSON 직접 사용)
- 지도 투영(projection) 설정 가능

**단점**
- `react-simple-maps`, `d3-geo` 패키지 추가 필요
- 번들 크기 증가

---

### 방식 C — SVG 이미지 + 오버레이

사전 제작된 충북 지도 SVG 이미지 위에 클릭 가능한 영역(div/area)을 수동으로 얹는다.

**단점**
- 이미지 위치와 오버레이 좌표를 수동으로 맞춰야 함
- 유지보수 어려움

---

## 권장: 방식 A

### 필요한 GeoJSON 파일

**사용자가 직접 다운로드해야 합니다.**

아래 두 곳 중 하나에서 충청북도 시군구 경계 GeoJSON을 받아주세요.

#### 옵션 1 — 통계지리정보서비스 (SGIS) ✅ 권장
1. https://sgis.kostat.go.kr 접속 → 회원가입
2. 상단 메뉴 → 자료제공 → 경계 데이터
3. 행정구역 → 시군구 → 충청북도 선택 → GeoJSON 또는 SHP 다운로드

#### 옵션 2 — 국가공간정보포털 (NSDI)
1. https://www.nsdi.go.kr 접속
2. 오픈마켓 → 행정구역도_시군구 검색
3. 충청북도 필터 후 다운로드

> SHP 파일을 받은 경우, 변환 스크립트에서 `geopandas`로 처리 가능하도록 준비해 둘 것.

---

### 파일 위치

다운로드한 파일을 아래 경로에 저장:

```
public/maps/chungbuk-sigungu.geojson
```

---

## 구현 단계 (파일 받은 후 내가 진행)

1. Python 변환 스크립트 작성
   - GeoJSON → 충북 시군구만 필터
   - 좌표 → SVG viewBox 기준 path로 변환
   - 각 region id(지역명) 포함

2. `src/components/chungbuk-map.tsx` 컴포넌트 작성
   - SVG path 하드코딩
   - `selectedRegion`, `onSelect` props
   - hover/선택 시 색상 변화

3. `home-container.tsx` 에 지도 컴포넌트 연결
   - 지역 클릭 → region 상태 업데이트
   - 이동 유형 선택 UI는 기존 유지
