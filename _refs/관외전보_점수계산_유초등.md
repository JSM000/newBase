# 청주교육지원청 유치원·초등교사 관외 전보 점수 계산 기준
> 근거: 충청북도청주교육지원청 초등교육공무원 인사관리기준 (2025.7.16. 개정, 2026.3.1. 시행)
> 서류 작성 기준일: **2026.2.28.**

---

## 1. 점수 총합 구조

```
총점 = 경력점 + 가산점 + 실적점
```

- 평정 기간: **현임교 근무 기준 최근 5년 이내**
- 모든 점수는 **NEIS 인사기록카드 등재 실적만 인정**

---

## 2. 경력점

### 2-1. 기본 경력점
- 현임교 근무 **월 1점**
- 최근 **5년(60개월) 이내** 경력만 평정
- 잔여일수 **15일 이상** → 1개월 인정 / **15일 미만** → 불인정

### 2-2. 경력 인정/불인정 기준

| 근무 구분 | 현임교 경력 산입 | 경력점 평정 |
|---|:---:|:---:|
| 일반 근무 | ✅ | ✅ |
| 일반 파견 | ❌ | ❌ |
| 일반 휴직 | ❌ | ❌ |
| 공무상 질병휴직 | ✅ | ❌ |
| 육아휴직 1년 미만 | ✅ | ❌ |
| 육아휴직 1년 이상 (연장 포함) | ❌ | ❌ |
| 원소속교 동일지역 행정기관 파견 | ✅ | ✅ |
| 행정파견·노조전임·늘봄지원실장 | ✅ | ✅ |
| 직위해제·정직·강등 기간 | ✅ | ❌ |

### 2-3. 육아휴직 세부 규칙
- 6개월 + 6개월 연장 = 총 1년 → **미산입**
- 1년 신청했으나 조기복직으로 1년 미만이 된 경우 → **산입**
- 휴직·파견 사이에 휴가·병가가 있으면 **연속으로 보지 않음**
- 육아휴직 중 학위취득(원격·야간대학원) 및 직무연수 실적점은 **인정 가능**

### 2-4. 특이사항
- 경력점이 만점이 되는 해까지 근무 가능
- 인정기간 내 점수를 **당겨쓸 수 있음** (5년 이내 범위에서)

### 3-2. 우대 가산점
> 월 **0.025점**, 중복 시 **유리한 것 하나만** 인정
> NEIS 가족란 미등재 시 서류 제출해도 **인정 불가**

| 항목 | 인정 조건 |
|---|---|
| ① 국가유공자 본인·배우자·자녀·손 봉양 | 경력기간 내 주민등록상 6개월 이상 사실상 봉양 |
| ② 75세 이상 노부모 봉양 (배우자 부모·조부모 포함) | 경력기간 내 주민등록상 6개월 이상 동거, 만 나이 기준 |
| ③ 장애 정도가 심한 장애인 배우자·직계 존비속 부양 | 경력기간 내 주민등록상 6개월 이상 부양 |
| ④ 18세 이하 자녀 3명 이상 부양 | 경력기간 내 주민등록상 6개월 이상 부양 기간만 인정 |
| ⑤ 2019.3.1. 이후 둘째 자녀 출산 | 둘째 자녀 출산 후 **최초 전보 1회**에 한함, 부부교사는 1인만 |

### 4-5. 직무연수 실적

- 학년도 단위 **60시간(4학점) 이상**이면 **연 1회 → 0.5점**
