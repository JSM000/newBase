# 5. 탭+필터 바 접기/펼치기 (지도 위 오버레이로 전환)

## 요청 내용

"탭과 필터 부분을 접었다 폈다 할 수 있으면 좋겠다. 사이드바와 마찬가지로 지도 위쪽으로
덮어씌워지도록. 지도가 화면에서 최대한 많은 면적을 차지하고 그 외 기능들은 열었다
닫았다 하는 게 좋을 것 같다."

기존엔 `SchoolFilterBar`가 지도 위에 고정된 한 줄짜리 바(flex 형제)로 항상 자리를 차지해서,
지도 높이가 그만큼 줄어들어 있었다.

## 해결: 필터 바를 지도 컨테이너 안으로 옮겨 절대 위치 오버레이로

`SchoolRankingPanel`/`CommutePanel`/`SchoolDetailPanel`(오른쪽 사이드바)과 같은 패턴 —
지도 크기(`<KakaoMap>`)는 항상 컨테이너 전체를 채우고, 그 위에 `absolute`로 떠 있는
카드가 열림/닫힘만 토글된다.

```tsx
// statistics-container.tsx
const [filterBarOpen, setFilterBarOpen] = useState(false); // 기본: 접힘(지도 최대화)

<div className="relative min-h-0 flex-1 p-3">
  <KakaoMap ... controlsTopOffset={filterBarOpen} />

  <div className="pointer-events-none absolute inset-x-3 top-3 z-30">
    <div className="pointer-events-auto inline-block max-w-full">
      <SchoolFilterBar
        ...
        collapsed={!filterBarOpen}
        onToggleCollapsed={() => setFilterBarOpen((v) => !v)}
      />
    </div>
  </div>
  {/* 범례·상세/순위/길찾기 패널 등은 그대로 */}
</div>
```

바깥 래퍼에 `pointer-events-none` + 안쪽 카드에 `pointer-events-auto`를 쓴 이유: 오버레이
래퍼가 `inset-x-3`로 가로 전체 폭을 차지하지만, 카드 자체는 `inline-block`이라 내용만큼만
너비를 갖는다 — 카드 오른쪽의 빈 공간까지 클릭을 막으면 그 아래 지도를 못 눌러서, 래퍼는
클릭을 통과시키고 카드에서만 다시 받도록 함(기존 사이드바 패널들엔 없던 문제 — 그쪽은
카드가 옆면 전체를 채워서 빈 공간이 안 생김).

## `SchoolFilterBar` 자체가 접힘/펼침 두 형태를 그림

새 props `collapsed`/`onToggleCollapsed`. 접혔을 때는 지금 탭 이름 + 학교 수만 보여주는
알약 버튼, 펼쳤을 때는 기존 탭+필터 내용 그대로에 접기 버튼(`ChevronUp`)만 추가:

```tsx
if (collapsed) {
  return (
    <button onClick={onToggleCollapsed} className="... rounded-xl border bg-white/95 shadow-custom ...">
      <ChevronDown className="h-4 w-4" />
      {view === 'ranking' ? '순위 보기' : '출퇴근 시간 계산기'} · {resultCount}개 학교
    </button>
  );
}
// 펼친 상태: 기존 탭 줄 오른쪽에 ChevronUp 접기 버튼 추가, 전체를 rounded-xl + shadow-custom 카드로
```

기존엔 필터 바 바깥 div가 `border-b border-zinc-100 bg-white`(지도와 나란히 붙은 바)였는데,
이제 지도 위에 뜬 카드라 `rounded-xl border border-zinc-200 shadow-custom`으로 바꿨다.

## 기본값: 처음엔 펼침

처음엔 "지도가 최대한 많은 면적을 차지"를 그대로 반영해 `filterBarOpen` 초깃값을 `false`
(접힘)로 뒀는데, "페이지에 처음 접근했을 때 설정 바가 열린 상태이도록"이라는 요청으로
`true`(펼침)로 바꿨다 — 처음 들어왔을 때 필터를 바로 볼 수 있어야 한다는 쪽으로 결론.
접었다 펴는 기능 자체는 그대로라 사용자가 원하면 여전히 접어서 지도를 넓게 볼 수 있다.
탭이 뭘 보여줄지(`statsView`)와 필터 바가 펼쳐져 있는지(`filterBarOpen`)는 서로 다른
상태라, 필터 바를 접어도 이미 골라둔 탭/필터 값은 그대로 유지된다.

## 왼쪽 위 지도 컨트롤(학교 개별 마커/행정구역 경계 스위치) — 처음엔 위치 조정, 최종은 필터 바로 이동

**1차 시도**: 필터 바 오버레이가 지도 왼쪽 위(`left-3 top-3`)에서 시작하는데, `KakaoMap`
자체의 두 스위치 컨트롤도 같은 자리에 떠 있어서 필터 바를 펼치면 겹쳤다. `controlsTopOffset`
prop으로 필터 바가 펼쳐졌을 때만 스위치를 아래(`top-44`)로 밀어내는 방식으로 고쳤다.

**최종**: 곧바로 "이 스위치들도 필터 아래에 넣어서 같이 접었다 폈다 하자"는 요청이 와서,
겹침을 피하는 위치 조정이 아니라 **컨트롤 자체를 필터 바 안으로 옮기는** 방향으로 정리했다
— `controlsTopOffset`은 삭제. 자세한 내용은 [06_지도컨트롤_필터바로이동.md](06_지도컨트롤_필터바로이동.md).

## z-index: 좁은 화면에서는 사이드바가 필터 바보다 위에 보이도록

"사이드바가 설정바보다 위쪽에 표시되도록 해줘. 창의 가로 길이를 줄이면 사이드바가
우선적으로 보이도록" — 필터 바(위쪽 오버레이)와 오른쪽 사이드바(순위/상세/길찾기 패널)가
둘 다 절대 위치라, 창 폭이 좁아지면 오른쪽 사이드바(`w-full max-w-sm`)가 사실상 화면
전체 폭을 차지해서 위쪽 필터 바와 겹친다. 원래 필터 바가 `z-30`, 사이드바가 `z-20`이라
겹치면 필터 바가 사이드바를 덮었는데, 요청대로 순서를 뒤집었다:

- 필터 바 오버레이(`statistics-container.tsx`): `z-30` → `z-20`
- 사이드바 3개(`commute-panel.tsx`, `school-ranking-panel.tsx`, `school-detail-panel.tsx`):
  `z-20` → `z-30`
