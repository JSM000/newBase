# 통계지도 UI 개선 — 수정 내역 (목차)

**브랜치**: `feat/statistics-ui-improvements` (main 기준 분기)
**범위**: 이 문서는 `git diff main`을 기준으로, 이 브랜치에서 실제로 바뀐 내용만 담는다.
(집 위치 🏠 상시 마커 등 이전 브랜치(`feat/user-settings-page`)에서 이미 main에 들어간
기능은 여기 포함하지 않는다 — `git show main:src/components/kakao-map/kakao-map.tsx`로
확인함.)

## 배경 / 목적

통계지도(`/statistics`)의 필터 바 하나가 "순위 보기"와 "출퇴근 시간 계산"이라는 서로 다른
두 기능을 같이 다루고 있어서 처음 쓰는 사람에게 헷갈린다는 문제 제기로 시작해서,
지도 위 마커·범례·컨트롤 UI까지 이어서 손봤다.
