# 4. 지도 컨트롤 버튼 → 라벨 + on/off 스위치 UI

## 요청 내용

지도 왼쪽 위의 "학교 개별 마커 보기"/"행정구역 경계 끄기" 버튼(텍스트가 상태에 따라
바뀌는 토글 버튼) 방식을, "왼쪽에 고정 설명 텍스트 + 오른쪽에 on/off 스위치"로 바꿔달라는
요청.

## 신규: `src/components/ui/switch.tsx`

이 프로젝트엔 `@radix-ui/react-switch` 의존성이 없다(다른 shadcn 컴포넌트들은 각자
필요한 radix 패키지만 설치돼 있는 구조). 새 패키지를 추가하는 대신, `role="switch"`
버튼으로 직접 구현:

```tsx
<button type="button" role="switch" aria-checked={checked} onClick={() => onCheckedChange(!checked)}>
  <span className={checked ? 'translate-x-4' : 'translate-x-0.5'} />
</button>
```

## `kakao-map.tsx` 적용

```tsx
<div className="flex items-center gap-2 rounded-lg border ...">
  <span className="w-[4.75rem] whitespace-nowrap">학교 개별 마커</span>
  <Switch checked={showAllMarkers} onCheckedChange={setShowAllMarkers} />
</div>
<div className="flex items-center gap-2 rounded-lg border ...">
  <span className="w-[4.75rem] whitespace-nowrap">행정구역 경계</span>
  <Switch checked={showBoundaries} onCheckedChange={setShowBoundaries} />
</div>
```

## 스타일 조정 과정 (시행착오)

두 라벨("학교 개별 마커" 8자, "행정구역 경계" 7자) 길이가 달라서 여러 번 조정했다:

1. `w-40` 고정 너비 + `justify-between` → 짧은 라벨 쪽 텍스트-스위치 간격이 너무 벌어짐
2. `w-40` + `justify-between` 제거(→ `gap-2`만) → 카드 자체가 너무 넓고, 두 카드 너비가
   서로 달라 보임(auto 폭)
3. **최종**: 라벨 `<span>`에 고정 너비 `w-[4.75rem]`(76px) + `whitespace-nowrap` — 두
   카드 너비와 텍스트-스위치 간격이 둘 다 일정해지면서, 카드가 불필요하게 넓지도 않음

## 색상 관련 확인 사항

스위치 on 색상(`bg-primary`)이 코랄/빨강 계열(`#e77474`)로 보이는 건 버그가 아니라 이
프로젝트의 tailwind `primary` 색상 자체가 그 값이다(`tailwind.config.js` 확인 —
`secondary`가 파란 계열 `#0072a1`). "행정구역 경계 끄기" 버튼의 강조색을 흰색/primary로
바꿔달라는 요청도 있었으나, 최종적으로는 "원래대로(켜짐=primary 강조, 꺼짐=흰색)"가
자연스럽다는 판단으로 원상 복귀했다.
