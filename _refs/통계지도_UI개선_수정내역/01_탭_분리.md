# 1. 필터바 탭 분리 (순위 보기 / 출퇴근 시간 계산기)

## 이전 상태

필터바(`school-filter-bar.tsx`) 하나에 "순위 보기"·"출퇴근 시간 계산기" 버튼이 다른
필터 컨트롤들과 나란히 있어서, 이 필터바가 두 가지 다른 기능을 같이 다룬다는 게
직관적으로 안 보였다.

## 1차: 탭으로 전환

필터바 가장 위 줄에 `Tabs`(`@/components/ui/tabs`, 기존 shadcn 컴포넌트 재사용)로
"순위 보기" / "출퇴근 시간 계산기" 탭을 만들고, 기존 두 버튼을 없앴다. `SchoolFilterBar`에
`view`/`onViewChange` prop 추가.

탭에 따라 아래 필터 행도 바뀐다:
- **순위 보기 탭**: 설립구분·학교급·시·군 + **표시·순위 기준** 드롭다운
- **출퇴근 시간 계산기 탭**: 설립구분·학교급·시·군 + **집주소 검색**(2번 문서)

("표시·순위 기준"은 순위 정렬 기준이라 출퇴근 탭에선 의미가 없어서 숨김.)

## 2차: 탭 선택과 사이드바 열림을 분리

처음엔 탭을 누르면 곧바로 `panelMode`가 바뀌어 사이드바(순위 목록 / 길찾기 패널)가
열렸는데, "탭을 누르면 사이드바가 안 나오게 하고, 버튼을 눌렀을 때만 사이드바가 나오면서
결과가 보이게 해달라"는 요청으로 다시 나눴다.

- `statistics-container.tsx`에 **`statsView`**(탭 선택, `StatsView` 타입) state를
  새로 추가 — 필터바의 `view`/`onViewChange`는 이제 이 state만 다룬다.
- 기존 `panelMode`(사이드바가 실제로 열렸는지)는 그대로 두고, **분리**했다:
  - 순위 보기 탭: "표시·순위 기준" 드롭다운 옆에 **"순위 보기" 버튼**을 새로 추가 —
    눌러야 `setPanelMode('ranking')`.
  - 출퇴근 탭: 기존 "검색" / "저장된 집 위치" 버튼 클릭 시 검색 실행과 함께
    `setPanelMode('commute')`도 같이 호출하도록 수정(새 버튼을 안 만들고 기존 액션에
    얹음).

## 왜 두 state로 나눴는가

- `statsView`: "지금 필터바에 어떤 필터 종류를 보여줄지" — 항상 `ranking`/`commute` 둘 중
  하나(중립 상태 없음, 기본값 `ranking`).
- `panelMode`: "지금 사이드바에 뭐가 열려 있는지" — `none`/`ranking`/`detail`/`commute`
  네 가지, 학교 상세를 보다가 돌아올 자리(`returnMode`)도 이걸 기준으로 계산.

지도 마커·범례·툴팁의 "출퇴근 모드냐 아니냐" 판단(3번 문서)도 `panelMode`가 아니라
`statsView` 기준으로 만들었다 — 탭만 선택해도(사이드바를 아직 안 열었어도) 마커 스타일이
바로 바뀌어야 자연스럽기 때문.

## 3차: 학교명 검색 위치 — 탭 줄 → 필터 행 → 지도 컨트롤(스위치) 줄

옮긴 순서:
1. "탭 오른쪽, 가장 오른쪽 위 모서리로" → 탭 줄(접기 버튼 옆)
2. "오른쪽 아래로 옮기자" → 원래 있던 필터 행(설립구분/학교급/시·군과 같은 줄) 맨 오른쪽
3. "여기 말고, 학교 개별 마커/행정구역 경계 버튼이 있는 줄로" → **최종**: 맨 아래
   지도 컨트롤 줄(`06_지도컨트롤_필터바로이동.md`에서 만든 스위치 두 개가 있는 줄) 오른쪽
   끝, `ml-auto`로 붙임.

필터 행(설립구분/학교급/시·군 + 표시·순위 기준 또는 집주소 검색)엔 이제 결과 개수
(`{resultCount}개 학교`)만 `ml-auto`로 오른쪽에 남아 있다.

## 4차: 결과 개수("N개 학교")를 탭 줄, 탭 바로 오른쪽으로 이동

"475개 학교 이거는 출퇴근 시간 계산기 버튼 오른쪽으로 옮기자" — 필터 행 맨 오른쪽에 있던
결과 개수를 맨 위 탭 줄로 옮겼다. `Tabs`를 감싸는 `div`(`flex items-center gap-3`)를
새로 만들어 `Tabs` 바로 옆에 개수를 붙이고, 이 묶음 전체가 탭 줄의 왼쪽에, 접기 버튼이
오른쪽에 오도록(`justify-between`) 배치했다. 필터 행에는 더 이상 결과 개수가 없다.

## 연동 지점

- `src/containers/statistics/school-filter-bar.tsx` — `Tabs` UI, `view`/`onViewChange`/
  `onShowRanking` props, 학교명 검색 입력창 위치(탭 줄 오른쪽 위)
- `src/containers/statistics/statistics-container.tsx` — `statsView` state, 탭·버튼
  클릭 핸들러
