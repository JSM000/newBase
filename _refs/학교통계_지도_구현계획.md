# 학교 통계 지도 기능 구현 계획

> 목표: 전보를 고려하는 교사가 지도에서 학교를 선택해 그 학교의 참고 통계(점수 산정 관련 + 근무 난이도·편의성)를 확인할 수 있게 한다.
> 데이터 소스: 학교알리미 OpenAPI (`_refs/학교알리미_OpenAPI_출력값.xlsx` 참고, API 키 보유)
> 지도 렌더링: 카카오맵 JavaScript SDK

---

## 1. 범위

- **지역**: 충청북도 전역만 (확정 — 전국 확장 없음)
- **학교급**: 유치원 + 초등학교 + 중학교 + 고등학교 전체
- **설립구분**: 공립 우선 (사립 포함 여부는 추후 결정)

---

## 3. 아키텍처

### 3-1. 데이터 수집 파이프라인 (배치, 런타임 API 호출 없음)

- 학교알리미 OpenAPI를 배치 스크립트로 호출해 충북 유·초·중·고 전체 학교의 채택 항목(2-1, 2-2)을 수집
- `SCHUL_CODE`(정보공시 학교코드) 기준으로 여러 시트(엔드포인트) 응답을 병합해 학교 1건당 통계 객체 구성
- 결과를 정적 JSON으로 저장 (예: `src/data/schools/chungbuk-schools.json`), 앱은 이 파일만 읽음 — 페이지 로드 시 학교알리미 API를 직접 호출하지 않음
- 갱신 주기: 학교알리미 공시 주기(연 1~2회)에 맞춰 스크립트 수동 재실행 (기존 인사계획 PDF/지도 데이터와 동일한 "사전 수집" 철학)

### 3-2. 지도 렌더링 (카카오맵)

**설계 원칙: 카카오 API 호출 최소화**
- Kakao Maps JavaScript SDK를 **지도 최초 렌더링 시 1회만** 스크립트 로드 (appkey 사용)
- 이후 마커 생성·hover 툴팁·click 상세 패널은 전부 **3-1에서 이미 수집해둔 정적 데이터**로 클라이언트에서 렌더링 — 추가 API 호출 없음
- Geocoding·장소검색 등 다른 카카오 API는 사용하지 않음 (위경도는 학교알리미가 이미 제공하므로 좌표 변환 자체가 불필요)

**마커 클러스터링 (필수)**
- 유초중고 전체면 마커가 수백 개라 축소된 지도에 전부 표시하면 가독성이 떨어짐
- Kakao Maps SDK 표준 `MarkerClusterer` 사용 — 축소 시 지역 단위로 묶어서 개수만 표시, 확대하면 개별 학교 마커로 분리
- SDK 내장 기능이라 추가 네트워크 호출 없음 (3-2의 "API 호출 최소화" 원칙 유지)

### 3-3. UI 구성 (가칭 `/statistics` 라우트)

**필터/검색 (상단)**
- 학교급 필터: 전체 / 유치원 / 초등학교 / 중학교 / 고등학교
- 지역 필터: 충북 시·군 단위 (청주/충주/제천/진천/음성 등 11개 시군)
- 학교명 검색

**표시 지표 선택 (범례 연동)**
- "표시할 통계" 선택 UI(드롭다운)로 2-1·2-2에서 채택한 지표 중 지도에 시각화할 값을 사용자가 고름 (예: 학생수, 학급당학생수, 교사 1인당 학생수 등 구간을 나눌 수 있는 수치형 지표)
- 선택한 지표 값에 따라 마커 색상/크기를 구간별로 다르게 표시 (예: 학생수 100명 미만/100~300/300~600/600 이상 4단계)
- 화면 한쪽에 현재 선택된 지표의 구간-색상 매핑을 보여주는 **범례** 표시
- 지표별 구간 기준(bucket 경계값)은 구현 단계에서 지표마다 별도 정의 필요 (지표마다 값 분포가 다름)

**지도 (중앙)**
- 카카오 지도 + 클러스터링 마커 (학교급별 아이콘/색상 또는 선택된 지표 기준 색상 중 택1 — 동시 표현 방식은 구현 단계 결정)
- hover: 학교명 + 핵심 지표 미니 툴팁
- click: 상세 패널(사이드시트) — 2-1(점수 참고) / 2-2(근무여건 참고) 두 섹션으로 구분 표시

## 4. 미해결 사항 / 사전 준비

1. **카카오맵 JavaScript API 키(appkey) 보유 여부** — 학교알리미 API 키와 별도로 Kakao Developers에서 발급 필요, 확인 필요
2. 사립학교 포함 여부
3. 연구·시범학교 지정 여부는 학교알리미로 확인 불가 → 필요 시 별도 소스 검토
4. "표시 지표 선택" 대상 지표별 구간(bucket) 경계값 정의 — 지표마다 값 분포가 달라 구현 단계에서 별도 확정 필요

---

## 5. 구현 순서 (제안)

1. 학교알리미 OpenAPI 배치 수집 스크립트 작성 (충북 유초중고 전체, 채택 항목만)
2. 수집 결과를 학교코드 기준 정적 JSON으로 병합·저장
3. 카카오맵 컴포넌트 작성 — SDK 1회 로드 + 정적 데이터 기반 마커 렌더링 + MarkerClusterer 적용
4. 마커 hover/click 시 통계 패널 UI (2-1/2-2 섹션 구성)
5. 학교급 필터 · 지역(시군) 필터 · 학교명 검색 UI
6. "표시 지표 선택" 드롭다운 + 지표별 구간 정의 + 범례 UI + 마커 색상/크기 동적 반영
7. 라우트 연결 및 기존 화면과의 진입 경로 결정
