# 유치원·초등교사 관외 전보 대상 여부 판단 기준
> 기준일: 2026.2.28. / 2026.3.1.자 관외 전보 적용

---

## 전보 유형 3가지

| 유형 | 설명 |
|---|---|
| **지역만기** | 청주시 지역 근무연한 초과 → 전보 **필수**, 희망지 2개 작성 |
| **학교만기** | 현임교 근무연한 초과 → 전보 **필수**, 희망지 3개 작성 |
| **일반희망** | 만기는 아니지만 자발적으로 이동 희망 → 희망지 1개 작성 |

> ※ 지역만기·학교만기는 **중복 해당 가능**  
> ※ 만기자는 전원 내신서 제출 의무

---

## 1. 학교만기 (현임교 근무연한)

### 판단 기준
- 현재 근무 중인 학교에서 **5년 이상** 근무한 경우

### 근무기간 계산 방법
- **인정되는 기간**: 일반 근무, 동일지역 행정기관 파견, 행정파견·노조전임·늘봄지원실장
- **인정되지 않는 기간 (이 기간은 5년에서 제외)**:
  - 일반 파견
  - 일반 휴직
  - 육아휴직 **1년 이상** (1년 미만은 산입)
  - 직위해제·정직·강등 기간은 산입은 되나 실질적으로 아래 예외 확인

> ※ 잔여일수 15일 이상이면 1개월 인정 / 15일 미만이면 불인정

### 특례: 이전재배치교 준비기간
아래 학교에서 해당 기간에 근무한 경우, 그 기간은 학교 근무연한에서 **제외** 가능
(단, 해당 기간의 경력점·실적점·가산점도 함께 사용 불가)

| 학교 | 준비기간 (연한 제외 가능 기간) |
|---|---|
| 상당초 | 2021.3.1. ~ 2024.2.29. |
| 복대초 | 2020.3.1. ~ 2023.2.28. |
| 신송초 | 2026.3.1. ~ 2029.2.28. |

### 특례: 임시배치교 교원
아래 개교로 인해 임시배치된 교사는 **이전학교 근무경력을 포함하여 전보 가능**

| 임시배치 시점 | 개교 학교 |
|---|---|
| 2020.3.1. | 용아초, 용아초병설유, 생명초, 생명초병설유, 동남유 |
| 2024.3.1. | 상당초, 오송솔미초 |
| 2025.3.1. | 솔강초, 솔강초병설유 |

## 2. 지역만기 (청주시 지역 근무연한)

### 청주시 내 지역 구분
- **동지역**: 청주시 내 '동' 주소 소재 학교
- **읍면지역**: 청주시 내 '읍·면' 주소 소재 학교

### 판단 기준 (아래 중 하나라도 초과하면 지역만기)

| 구분 | 연한 |
|---|---|
| 동지역 누적 근무 | **8년 초과** |
| 읍면지역 누적 근무 | **10년 초과** |
| 청주시 통산 (동+읍면 합산) | **13년 초과** |

> ※ **관외 기준**: 동 8년 / 읍면 10년 / 통산 13년  
> ※ **관내 기준**은 이보다 1년 빠름 (동 7년 / 읍면 9년 / 통산 12년) — 관외 전보에는 해당 없음

### 지역 근무기간 계산 방법
- 학교만기 계산과 동일하게, **인정되지 않는 기간은 연한에서 제외**
- 동지역·읍면지역 각각 **누적** 계산 (여러 학교에 걸쳐 합산)

### 영양교사 특례
- **2016.3.1. 이전에 인사이동이 없었던 영양교사**는 구 기준 적용:
  - 학교만기: 3년
  - 청주시 근무연한: 동·읍면 6년 / 통산 8년

## 3. 일반희망 신청 최소 조건

아래 조건을 **모두** 충족해야 일반희망 전보 신청 가능

### 필수 조건
| 조건 | 기준 |
|---|---|
| 현임교 최소 근무기간 | **2년 이상** |
| 휴직·파견 상태 | 2026.3.1.자 휴직(예정)·파견(예정)자는 **신청 불가** |

> ※ 복직 예정자·파견복귀 예정자는 신청 가능  
> ※ 희망지는 **1개 시군만** 작성  
> ※ 타 시군 → 청주 전보 시 동지역·읍면지역 구분하여 희망 **불가** (시군 단위로만 선택)

### 일반희망 전보 결과
- 희망교(1, 2지망)에 배치되면 전보
- 희망교에 **배치 안 되면 → 1년간 전보 없이 현임교 유지** (다른 학교로 강제 배치되지 않음)

## 4. 전보 불가 대상 (유형 무관)

| 사유 | 내용 |
|---|---|
| 2026.3.1.자 휴직 예정자 | 지역·학교 만기자도 내신서 제출 불가 (소속교에서 휴직 처리) |
| 2026.3.1.자 파견 예정자 | 동일 |
| 정년 잔여 1년 미만 | 내신서 제출 금지 |
| 현임교 1년 6개월 미만 (교원감) | 해당 없음 (교사 기준 적용) |

---

## 5. 전보유예 (만기여도 1년 더 있을 수 있는 경우)

아래 해당자는 만기여도 **1년 단위로 유예** 신청 가능

| 사유 | 조건 |
|---|---|
| 지역만기 1년 미만 | 지역 근무연한 만료까지 1년 미만 남은 자 (읍면 분교·농촌진흥지역 가급지 제외) |
| 정년 임박 | 정기전보일(3.1.)로부터 정년 잔여기간 **1년 6개월 이내** |
| 중증장애인 교사 특수학교 근무 | 장애의 정도가 심한 장애인 교사로서 특수학교 근무 중인 자 |
| 인사위원회 결정 | 학교 운영상 특히 필요하다고 인사위원회에서 심의·결정된 자 |

## 6. 판단 흐름 요약

```
[STEP 1] 현재 근무 상태 확인
  → 2026.3.1.자 휴직·파견 예정? → 전보 불가

[STEP 2] 학교만기 확인
  → 현임교 근무 5년 이상? → 학교만기 (전보 필수)

[STEP 3] 지역만기 확인
  → 동지역 8년 초과 OR 읍면지역 10년 초과 OR 통산 13년 초과?
  → 지역만기 (전보 필수)

[STEP 4] 둘 다 해당 없으면
  → 현임교 2년 이상? → 일반희망 신청 가능
  → 현임교 2년 미만? → 전보 신청 불가
```
