# 5. 엑셀 파일 (개인정보 필터링 기능 추가)

## 목적

재방문할 때마다 NEIS 인사기록카드를 다시 업로드하지 않아도, 지난번 계산 결과를 이어볼 수
있게 한다.

## 확정: 파싱이 끝난 구조화 데이터(`ParsedFile`)만 저장 (사용자 확인 완료)

`src/lib/excel-parser.ts`를 확인한 결과, 현재 파서는 이름·주민등록번호·사진·연락처 같은
직접 식별정보를 애초에 컬럼으로 읽지 않는다 — 추출 대상은 `career`(경력) / `awards`(포상) /
`research`(연구실적) / `training`(연수) / `degrees`(학위) / `supplementary`(보직) 뿐이다
(`src/types/score.ts`의 `ParsedFile` 참고).

**원본 xlsx 바이너리는 저장하지 않는다.** `ParsedFile`은 이미 원본 엑셀보다 훨씬
필터링된 상태이므로, 이 구조체를 그대로 `localStorage`에 JSON으로 저장하면 별도의
"개인정보 필터링 로직" 구현 없이 목적을 달성한다.

## 저장 값

```ts
savedParsedFile: {
  data: ParsedFile;   // src/types/score.ts
  savedAt: string;    // ISO 날짜 — 자동 삭제([06]) 판단 기준, 만료 시각 계산에 사용
} | null;
```

## 엑셀 관련 코드는 전부 `ExcelDataDialog` 모달 하나로 통합 (구현 완료)

처음엔 계산기(`upload-section.tsx` + `use-parse-excel.ts`)와 설정 페이지가 각자 자기
파싱 로직을 들고 있었는데, 그러다 보니 "계산기는 저장 전 확인 버튼을 거치고, 설정
페이지는 올리자마자 바로 저장"처럼 같은 동작이 곳에 따라 다르게 구현되는 **opt-in
불일치**가 생겼다. 그래서 파일 검증·드래그앤드롭·`parseExcelFile` 호출·저장·삭제를
**`src/components/excel-data-dialog.tsx`(`ExcelDataDialog`) 모달 하나에 전부 모으고**,
계산기·설정 페이지는 이 모달을 열기만 한다.

```ts
interface ExcelDataDialogProps {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  /** 있으면 "계산기 모드", 없으면 "설정 모드" */
  onParsed?: (parsed: ParsedFile) => void;
}
```

- **계산기 모드** (`onParsed` 제공, `upload-section.tsx`): 파싱 성공 시 **저장하지 않고**
  곧바로 `onParsed(parsed)`로 넘겨 점수 계산 + 결과 화면 이동까지 호출자가 처리, 모달은
  닫힌다. 저장 여부는 기존처럼 계산 결과 화면의 "이 기기에 저장" 버튼에서 별도로 opt-in
  (이 버튼은 이미 파싱된 데이터를 저장만 하는 한 줄짜리 호출이라 "엑셀 파싱" 코드로 보지
  않고 모달 밖에 그대로 둠).
- **설정 모드** (`onParsed` 없음, `settings-container.tsx`): 파싱 성공 시 **바로 저장**
  (`saveParsedFile`). 이 모달을 여는 행위 자체가 "인사기록카드 데이터 관리"라는 명확한
  의도이므로 별도 확인 단계 없이 저장 — 저장된 데이터 상태 표시·삭제 버튼도 모달 안에
  있다.

두 모드 다 파일을 서버로 보내지 않으므로, `next.config.ts`의 CSP와
`scripts/check-no-network-in-score-calc.mjs`의 정적 스캔 대상에 `excel-data-dialog.tsx`와
설정 페이지 관련 파일을 포함시켰다 (`SCANNED_PATHS` 참고 — CLAUDE.md도 갱신).

## 연동 지점 (자동화 — [08_자동화.md](08_자동화.md) 참고)

- `src/components/excel-data-dialog.tsx` — 파일 검증·드래그앤드롭·`parseExcelFile`
  뮤테이션·저장·삭제, 계산기/설정 페이지 공용
- `src/containers/score-calculator/upload-section.tsx` — 모달을 열고, `onParsed`로 받은
  결과로 `calculateScore` 실행 + 결과 화면 이동 (예전 `use-parse-excel.ts` 훅은 삭제하고
  이 로직을 그대로 옮겨왔다)
- `src/containers/settings/settings-container.tsx` — 모달을 여는 버튼 하나만 남음
- `src/store/use-score-store.ts` / `score-calculator-container.tsx`: `savedParsedFile`이 있으면
  계산기 진입 시 업로드 화면을 건너뛰고 바로 결과 화면으로 이동 (자세한 내용은 08 참고)
