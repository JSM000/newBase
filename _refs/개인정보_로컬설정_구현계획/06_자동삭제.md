# 6. 주기적 자동 삭제

## 확정 (사용자 확인 완료)

- **주기: 20일**, 전 항목 일괄 삭제
- 20일 뒤 삭제된다는 사실을 안내하고, **정확히 언제(날짜+시간) 삭제되는지도 화면에 표시**한다.

## 구현 방식 (실제 구현 기준)

1. 설정 저장(zustand `persist`) 시 최상위에 `savedAt: string`(ISO) 기록
2. `src/lib/settings-retention.ts`에 만료 체크 + 만료 시각 계산 함수 작성

```ts
export const RETENTION_DAYS = 20;

export function getExpiresAt(savedAt: string): Date {
  return new Date(new Date(savedAt).getTime() + RETENTION_DAYS * 24 * 60 * 60 * 1000);
}

export function isExpired(savedAt: string): boolean {
  return Date.now() > getExpiresAt(savedAt).getTime();
}
```

3. `src/store/use-user-settings-store.ts`의 `checkExpiry()` 액션이 `savedAt`을 확인해
   만료됐으면 즉시 전체 `reset()`(=localStorage 값도 기본값으로 덮어써 사실상 삭제).
4. 앱 최상위(`src/components/provider/settings-expiry-check.tsx`)에서 마운트 시 1회
   `checkExpiry()`를 호출 — 계산기/통계 컨테이너도 저장된 데이터를 자동으로 불러올 때
   각자 다시 한번 만료 여부를 확인한다(자세한 흐름은 아래 "왜 여러 곳에서 확인하는가" 참고).
5. 설정 페이지 및 안내 배너([07](07_개인정보안내.md))에 `getExpiresAt(savedAt)`을 사람이
   읽을 수 있는 형식(`src/utils/formatter.ts`의 `formatDateTime`)으로 노출

```
예: "2026년 10월 9일 오후 3시 12분에 자동으로 삭제됩니다."
```

## 왜 여러 곳에서 확인하는가

"주기적으로 삭제"라고 해서 백그라운드에서 시간이 흐르는 걸 감시하는 타이머 같은 건 없다 —
브라우저 탭이 꺼져 있으면 어차피 아무 코드도 실행되지 않기 때문에 그런 타이머는 의미가
없다. 대신 **"이 데이터를 다음에 누가 읽으려는 시점"마다 그때 가서 유통기한을 확인**하는
방식이다:

1. 저장할 때(`saveParsedFile`, `setCurrentSigungu` 등) 매번 `savedAt`을 현재 시각으로 갱신
2. 앱이 열릴 때마다(`SettingsExpiryCheck`, 계산기/통계 컨테이너 마운트 시) `savedAt +
   RETENTION_DAYS`와 지금 시각을 비교
3. 지났으면 그 순간 `reset()` → 스토어 상태가 기본값으로 바뀌고, zustand `persist`
   미들웨어가 이 변경을 그대로 localStorage에도 덮어써서 실제 삭제가 일어난다

즉 "20일째 되는 정각"에 정확히 지워지는 게 아니라, **20일이 지난 뒤 이 앱을 다음에 열었을
때** 지워진다 — 브라우저를 계속 켜두지 않는 이상 이 정도 오차는 문제되지 않는다.

## 연동 지점

- `src/store/use-user-settings-store.ts` — `savedAt` 필드 + `checkExpiry()`/`reset()` 액션
- `src/lib/settings-retention.ts` — `RETENTION_DAYS`, `getExpiresAt`, `isExpired`
- `src/utils/formatter.ts` — `formatDateTime` 날짜/시간 표시 헬퍼
- `src/components/provider/settings-expiry-check.tsx` — 앱 진입 시 1회 체크
- `score-calculator-container.tsx` / `statistics-container.tsx` — 저장된 데이터를 자동으로
  불러오는 시점에도 각자 만료 여부를 재확인
