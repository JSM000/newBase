# 개인정보 로컬 설정 저장 — 구현 계획 (목차)

## 배경 / 목적

계산기(`/calculator`)와 통계(`/statistics`) 두 페이지에서 매번 다시 입력해야 하는 개인
조건들을 `/settings` 한 곳에 저장해두고, 재방문 시 자동으로 불러와 **선택 과정 없이 바로
결과를 보여주는 것**까지가 목표다 ([08](08_자동화.md)).

- **저장 위치는 브라우저 `localStorage`뿐** — 어떤 항목도 서버로 전송하지 않는다.
  기존 "개인정보 보호 원칙(불변조건)"(`CLAUDE.md`)을 그대로 계승하되, *영구 로컬 저장*이라는
  새로운 성격이 추가되므로 반드시 opt-in + 명시적 안내로 설계한다 ([07](07_개인정보안내.md)).
- 기술 방식: zustand `persist` 미들웨어로 새 스토어 `src/store/use-user-settings-store.ts`를
  만들고 `localStorage` 키(예: `newbase-user-settings`)에 저장한다. (프로젝트에 이미
  `zustand/middleware`의 `persist`가 설치되어 있음 — 신규 의존성 불필요)

## 확정된 결정 사항

1. **현 근무 지역** = 현재 근무 중인 시·군·구(`CHUNGBUK_SIGUNGU_ORDER` 11개 중 하나).
   지역가산 급지 구분(`schoolZone`)·부장교사 근무지역(`headTeacherSchoolZone`)과는
   별개이며, 그 값들은 계속 계산기 화면에서 수동 입력. → [01](01_근무지역.md)
2. **엑셀 파일**은 원본 xlsx가 아니라 **이미 파싱된 구조화 데이터(`ParsedFile`)만** 저장.
   → [05](05_엑셀파일.md)
3. **자동 삭제 주기는 20일**, 전 항목 일괄 삭제. 화면에는 정확한 삭제 일시(날짜+시간)를
   표시. → [06](06_자동삭제.md)
4. **거주지는 좌표(`lat`, `lng`)만 저장**, 상세 주소 문자열은 저장하지 않음. → [03](03_거주주소.md)
5. 저장된 데이터가 있으면 계산기는 지역 선택·업로드 화면을, 통계지도는 시·군/학교급 선택과
   주소 검색을 건너뛰고 곧바로 결과를 보여준다. → [08](08_자동화.md)
6. **관외전보 고려 중이면 이동 희망 시·군(`desiredSigungu`)도 저장** — 통계지도 기본
   검색 대상 지역은 "떠나려는 지역"이 아니라 이 희망 지역을 우선한다. → [02](02_전보유형.md)
