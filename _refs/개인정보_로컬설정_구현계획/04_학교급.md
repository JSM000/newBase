# 4. 학교급

## 현재 상태 (구현 시점 기준)

처음엔 점수 계산기의 `UserInputs.teacherType: 'elementary' | 'kindergarten'`
(`src/types/score.ts`)을 그대로 재사용했는데, 통계지도는 초/중/고 전체를 다루는 데 반해
점수 계산기는 현재 유초등만 구현돼 있어(**영구 제약 아님 — 중고등 계산 로직도 추후
구현 예정, `CLAUDE.md` 참고**) 두 값 범위가 안 맞았다. 그래서 설정 페이지 전용 타입으로
분리했다.

```ts
// src/types/user-settings.ts
export type SchoolLevel = 'kindergarten' | 'elementary' | 'middle' | 'high';

schoolLevel: SchoolLevel | null; // null = 아직 선택 안 함 — 저장되는 값엔 'all'이 없다
```

폼에서는 4개 옵션(유치원/초등학교/중학교/고등학교) + "전체" 하나를 보여주고, **폼 맨
위**에 배치한다(다른 항목보다 먼저 정해야 나머지 안내 문구·자동화 동작이 자연스럽게
갈린다).

## "전체"는 저장되는 값이 아니라 "선택 해제" 버튼이다

시행착오가 좀 있었다:
1. 기본값을 `'elementary'`로 뒀더니, 아무것도 고른 적 없어도 화면엔 항상 "초등학교"가
   선택된 것처럼 보였다.
2. 그래서 `null`(=아직 선택 안 함) + placeholder("선택하세요") 방식으로 바꾸고, select
   목록에서 "전체"를 아예 없앴다. 그런데 이러면 "나는 일부러 전체 범위를 보고 싶다"는
   의도를 표현할 방법이 없었다.
3. `'all'`을 실제 저장값으로 만들어 select에 넣어봤는데("전체"를 고르면 검은 글씨로
   "전체"가 남음), 확인해보니 이건 원하는 그림이 아니었다 — **"전체"를 누르면 그냥
   회색 placeholder("선택하세요")로 돌아가야 한다**는 게 실제 의도였다.

최종적으로 **`schoolLevel`엔 `'all'`이라는 값 자체가 없다.** select 목록엔 "전체"
항목이 있지만, 그걸 고르면 `onValueChange`에서 곧바로 `null`로 바꿔서 저장한다 —
Radix Select엔 선택을 "해제"하는 UI가 따로 없어서, "전체"를 그 해제 버튼으로 쓴
것뿐이다. 그래서 화면엔 늘 "선택 안 함"(placeholder)과 "구체적으로 고름" 두 상태만
존재하고, "전체를 명시적으로 골랐다"는 제3의 상태는 없다.

```tsx
// settings-container.tsx
onValueChange={(v) => setSchoolLevel(v === 'all' ? null : (v as SchoolLevel))}
```

**"관외/관내 전보 고려 여부"·"현재 근무 중인 시·군·구"도 같은 패턴**이다 — select
목록엔 "전체"가 있지만, 저장되는 `transferPreference`/`currentSigungu` 값에는
`'all'`이 존재하지 않고 항상 `null`로 정규화된다.

### select가 리셋 후에도 이전 값을 보여주던 버그

"저장된 정보 삭제"를 누르면 스토어 값은 바로 `null`로 바뀌는데도, Radix `Select`가
`value` prop이 문자열→`undefined`로 바뀔 때 내부 상태를 안 지우고 이전에 그렸던
선택지를 그대로 남겨두는 문제가 있었다(새로고침해야만 반영됨). `key={value === null
? 'unset' : 'set'}`을 `Select`에 줘서, "선택 안 함 ↔ 선택함" 경계를 넘을 때만 컴포넌트를
강제로 다시 마운트하도록 고쳤다 — 같은 상태 안에서 값만 바뀌는 일반적인 선택 변경은
리마운트 없이 그대로 동작한다.

## 두 소비처로 나뉘는 이유

- **점수 계산기** (`src/types/score.ts`의 `UserInputs.teacherType: 'elementary' |
  'kindergarten'`)는 현재 유초등만 구현돼 있어 `schoolLevel`이 `null`/`'middle'`/`'high'`면
  시딩할 방법이 없다 — 이 경우 `teacherType`은 그냥 건드리지 않는다. **중고등 계산 로직이
  나중에 추가되면 이 분기도 같이 넓혀야 한다** — 지금 이렇게 나눠둔 건 계산기가 중고등을
  "영영 지원 안 함"이어서가 아니라 "아직 없어서"다.
- **통계지도** (`SchoolLevelFilter`: `'02'`(초)/`'03'`(중)/`'04'`(고)/`'all'`)는 `null`과
  `'kindergarten'` 둘 다 매칭 대상이 없어 `'all'`(전체 표시)로 둔다.

```ts
// score-calculator-container.tsx / upload-section.tsx (계산기 진입점)
if (schoolLevel === 'elementary' || schoolLevel === 'kindergarten') {
  updateInput('teacherType', schoolLevel);
}

// statistics-container.tsx
function resolveTargetLevel(settings): SchoolLevelFilter {
  switch (settings?.schoolLevel) {
    case 'elementary': return '02';
    case 'middle': return '03';
    case 'high': return '04';
    default: return 'all'; // kindergarten, null(미선택)
  }
}
```
