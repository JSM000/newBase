# 1. 현 근무 지역

## 확정 (사용자 확인 완료)

**현재 근무 중인 시·군·구**를 말한다. 계산기의 지역가산 급지 구분(`schoolZone`)이나
부장교사 근무지역(`headTeacherSchoolZone`)과는 **별개 개념**이다 — 그 값들은 여전히
계산기 결과 화면(`score-tab.tsx`)에서 그때그때 직접 입력한다(이번 로컬 설정 범위 아님).

## 재사용 가능한 기존 자산

`src/lib/school-region.ts`의 `CHUNGBUK_SIGUNGU_ORDER`에 이미 충북 11개 시·군 목록이
정의돼 있다(청주시·충주시·제천시·괴산군·단양군·보은군·영동군·옥천군·음성군·증평군·진천군).
통계 페이지 시·군 필터(`SchoolFilterBar`)도 같은 목록 기반이므로, 이 배열을 그대로
select 옵션으로 재사용한다.

## 저장 값

```ts
currentSigungu: string | null; // CHUNGBUK_SIGUNGU_ORDER 중 하나, 미입력 시 null
```

## 연동 지점 (자동화 — [08_자동화.md](08_자동화.md) 참고)

- `statistics-container.tsx`의 `sigungu` 필터 state 초기값을 이 값으로 채워서, 통계
  페이지 진입 시 시·군 선택 단계를 생략한다.
