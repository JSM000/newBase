# 2. 관외/관내 중 고려 중인 선택지

## 현재 상태

`transfer-eligibility.ts`에 학교만기·지역만기·일반희망 등 **전보 대상 여부 판단 기준**은
있지만, "관외로 나갈지 관내에 남을지 아직 고민 중"이라는 사용자의 **의향(preference)**을
저장하는 필드는 없다.

## 저장 값

```ts
type TransferPreference = 'external' | 'internal';

transferPreference: TransferPreference | null; // null = 아직 선택 안 함(placeholder) — 저장값엔 'all'이 없다
desiredSigungu: string | null;                 // 관외전보 시 이동을 희망하는 시·군 (transferPreference === 'external'일 때만 입력)
```

select 목록엔 "전체"가 있지만, 고르면 `onValueChange`에서 곧바로 `null`로 바뀐다 —
"전체"는 저장값이 아니라 선택 해제 버튼이다. 시행착오 배경은 [04_학교급.md](04_학교급.md)에
자세히 있다 — 학교급 select에서 겪은 것과 똑같은 문제였다. `currentSigungu`도 같은
패턴으로 `CHUNGBUK_SIGUNGU_ORDER` 목록 맨 위에 "전체"가 있다.

`desiredSigungu`는 설정 페이지에서 `transferPreference === 'external'`을 고른 경우에만
노출되는 추가 selector로, [01_근무지역.md](01_근무지역.md)의 `currentSigungu`와 같은
`CHUNGBUK_SIGUNGU_ORDER` 목록을 재사용한다.

## 활용처 (구현 완료)

- **통계 지도([03_거주주소.md](03_거주주소.md)·[08_자동화.md](08_자동화.md) 연동)**:
  관외전보를 고려 중이면 "지금 떠나려는 지역"이 아니라 "가고 싶은 지역"의 학교를 보는 게
  자연스러우므로, `transferPreference === 'external'`이고 `desiredSigungu`가 있으면
  통계지도·길찾기의 기본 검색 대상 시·군을 `desiredSigungu`로, 그 외(관내/미정)에는
  `currentSigungu`로 정한다 (`statistics-container.tsx`의 `resolveTargetSigungu`).
- **계산기([08_자동화.md](08_자동화.md) 8-3)**: `currentSigungu === '청주시'`이면서
  `transferPreference === 'external'`이면(=현재 이 앱이 지원하는 유일한 조합) 지역
  선택 화면(`/calculator`)의 지도·모달 선택을 건너뛰고 곧바로 `/calculator/score`로
  이동한다.

## 연동 지점

- `src/types/user-settings.ts` — `desiredSigungu` 필드

- `src/containers/settings/settings-container.tsx` — 관외 선택 시에만 보이는 "이동을
  희망하는 시·군" selector
- `src/containers/statistics/statistics-container.tsx` — `resolveTargetSigungu` 헬퍼
- `src/containers/score-calculator/region-select-container.tsx` — 지원 조합이면 자동 리다이렉트
