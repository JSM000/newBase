# 학교 비교 기능 — 구현 계획 (목차)

## 배경 / 목적

관심학교(즐겨찾기) 기능 설계 때부터 `_refs/즐겨찾기_구현계획/`(특히 01_저장방식.md,
03_목록보기.md)에서 여러 번 "그건 학교 비교 탭에서 다룬다"고 미뤄뒀던 바로 그 기능.
저장해둔 관심학교끼리 통계(학급수·학생수·수업시수 등)를 표로 나란히 비교한다.

- **대상**: 필터와 무관하게 **저장된 관심학교 전체**. 시·군/학교급 조건 없음(관심학교
  자체가 이미 "내가 고른 학교들"이라 추가 필터링이 의미 없음).
- **개수 제한 없음** — `favoriteCodes`에 있는 만큼 전부 열로 나열, 많아지면 표를
  가로 스크롤(`01_저장방식.md`의 "제한 필요해지면 스토어 아니라 비교 컴포넌트에서"
  메모를 그대로 따름).

## 확정 사항

1. 새 탭을 만들지 않고 **통계지도 필터 바의 기존 탭 체계에 세 번째 탭 "학교 비교"**로
   추가 — "학교 순위"/"출퇴근 시간 계산기"와 같은 패턴(탭 선택 → 버튼 눌러야 실제로
   열림). → [02](02_진입점.md)
2. 사이드바(`panelMode`, `max-w-sm`)가 아니라 **큰 모달**(`max-w-5xl`)로 연다 — 비교
   표는 학교마다 열이 하나씩 필요해서 좁은 사이드바에 안 맞음. → [02](02_진입점.md)
3. 비교 항목은 상세 패널의 `DETAIL_GROUPS`를 그대로 재사용 — 새 필드 정의 없이
   `field.render(school)`를 셀 값으로 직접 씀. 커뮤니티 지표(별점·조회수·관심학교
   등록 수)는 상세 패널과 별개로 맨 위에 직접 추가. → [01](01_비교표.md)
4. 각 열 헤더에 하트 토글(`FavoriteToggleButton`)을 둬서 비교하다가 바로 관심학교에서
   뺄 수 있게 함 — `_refs/즐겨찾기_구현계획/05_보존정책.md`에서 2차로 미뤄뒀던
   "목록에서 개별 삭제"가 여기서 해결됨.
5. 관심학교 0개/1개일 때는 표 대신 안내 문구("몇 개 더 필요해요" 류) — 비교는
   최소 2개부터 의미가 있음.
