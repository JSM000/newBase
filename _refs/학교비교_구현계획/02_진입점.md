# 2. 진입점 UI

## 탭 체계에 세 번째 탭으로 추가 (별도 메뉴 안 만듦)

`school-filter-bar.tsx`는 이미 "학교 순위"/"출퇴근 시간 계산기" 두 탭(`StatsView`)을
"탭 선택(필터 바 안 내용만 바뀜) → 버튼을 눌러야 실제 결과 화면이 열림" 패턴으로
쓰고 있다. "학교 비교"도 같은 패턴 — 탭을 누르면 필터 바에 "관심학교 N개 · 비교하기"
버튼만 보이고, 버튼을 눌러야 모달이 뜬다. 완전히 새로운 진입 경로(예: 헤더에 별도
아이콘, 떠다니는 플로팅 버튼)를 만들지 않은 이유: 이미 익숙한 자리(필터 바 탭)에
붙이는 게 발견하기 쉽고, 탭 전환 로직(`aria-hidden`/`invisible` 토글, 그리드 셀
공유)도 그대로 재사용할 수 있어서 코드 추가가 최소화됨.

**관심학교가 2개 미만이면 "비교하기" 버튼을 비활성화**하고 안내 문구를 보여준다 —
탭 자체는 항상 눌러볼 수 있게 둬서, 관심학교가 없는 사람도 이 기능이 있다는 걸
발견할 수 있게(버튼이 숨겨져 있으면 존재 자체를 모를 수 있음).

## `panelMode` 사이드바가 아니라 독립 모달

기존 상세/순위/길찾기 패널은 `statistics-container.tsx`의 `panelMode` state로
오른쪽 사이드바 한 자리를 공유한다(`max-w-sm`, 384px). 비교표는 학교 수만큼 열이
필요해서 이 폭에 안 맞는다 — 그래서 `panelMode`와 완전히 별개인 `compareOpen`
boolean 하나로 띄우는 **큰 모달**(`max-w-5xl`, 뷰포트의 거의 전체 폭)로 만들었다.
`panelMode`를 건드리지 않으므로, 비교 모달을 열어도 그 밑에 상세/순위 패널이 열려
있었다면 그대로 유지된다(서로 간섭 없음).

## 모달 크기·스크롤

`DialogContent`(shadcn, 기본 `max-w-lg`)에 `className="max-w-5xl w-[calc(100vw-2rem)] max-h-[85vh] overflow-hidden flex flex-col"`를
얹어서 덮어쓴다(`cn()`이 tailwind-merge 기반이라 나중에 준 클래스가 이김). 표 자체는
`overflow-auto`인 내부 div에 넣어 가로(학교 많을 때)·세로(항목 많을 때) 둘 다
스크롤되게 하고, `<thead>`/첫 번째 열에 `sticky`를 줘서 스크롤해도 학교명·항목명이
보이게 했다.
