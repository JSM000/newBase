# 청주교육지원청 초등교사 관외 전보 점수 계산 기준
> 근거: 충청북도청주교육지원청 초등교육공무원 인사관리기준 (2025.7.16. 개정, 2026.3.1. 시행)
> 2026.3.1.자 초등교육공무원 인사계획 (관외)
> 서류 작성 기준일: **2026.2.28.**

---

## 1. 적용 대상

**교사** (유치원, 초등, 특수, 보건, 사서, 영양, 전문상담)

---

## 2. 점수 총합 구조

```
총점 = 경력점 + 가산점 + 실적점
```

- 평정 기간: **현임교 근무 기준 최근 5년 이내**
- 기준일: **매년 2월 28일**
- 모든 점수는 **NEIS 인사기록카드 등재 실적만 인정**

---

## 3. 경력점

### 3-1. 기본 경력점
- 현임교 근무 **월 1점**
- 최근 **5년(60개월) 이내** 경력만 평정
- 잔여일수 **15일 이상** → 1개월 인정 / **15일 미만** → 불인정

### 3-2. 경력 인정/불인정 기준

| 근무 구분 | 현임교 경력 산입 | 경력점 평정 | 비고 |
|---|:---:|:---:|---|
| 일반 근무 | ✅ | ✅ | |
| 일반 파견 | ❌ | ❌ | |
| 일반 휴직 | ❌ | ❌ | |
| 공무상 질병휴직 | ✅ | ❌ | 경력 산입은 되나 점수 미평정 |
| 육아휴직 1년 미만 | ✅ | ❌ | 경력 산입은 되나 점수 미평정 |
| 육아휴직 1년 이상 (연장 포함) | ❌ | ❌ | |
| 원소속교 동일지역 행정기관 파견 | ✅ | ✅ | 경력·점수 모두 인정 |
| 행정파견·노조전임·늘봄지원실장 | ✅ | ✅ | 경력·점수 모두 인정 |
| 직위해제·정직·강등 기간 | ✅ | ❌ | 경력 산입은 되나 점수·가산점·실적점 미인정 |

### 3-3. 육아휴직 세부 규칙
- 6개월 + 6개월 연장 = 총 1년 → **미산입** (연장 시점에 1년이 되면 전체 미산입)
- 1년 신청했으나 조기복직으로 1년 미만이 된 경우 → **산입**
- 휴직·파견 사이에 휴가·병가가 있으면 **연속으로 보지 않음**
- 육아휴직 중 학위취득(원격·야간대학원) 및 직무연수 실적점은 **인정 가능**

### 3-4. 경력점 특이사항
- 휴직·파견자: 경력점이 만점이 되는 해까지 근무 가능
- 인정기간 내 점수를 **당겨쓸 수 있음** (5년 이내 범위에서)

### 5-5. 직무연수 실적

**기본 규칙**
- 평정기간 내 **학년도 단위**로 직무연수 **60시간(4학점) 이상**이면 **연 1회 인정 → 0.5점**
- **상한점: 2.5점** (최대 5회)
- 4학점(60시간) 미만이면 해당 연도 **불인정**
- 자격연수는 **제외**
- NEIS 등재 마감: **2025.12.31.**

**예시**
- 2025학년도 15시간 + 30시간 + 10시간 = 55시간 → **불인정** (60시간 미달)
- 2025학년도 20시간 + 25시간 + 20시간 = 65시간 → **인정** (0.5점)

**중복 수강 인정 기준**

| 상황 | 인정 여부 |
|---|---|
| 동일·유사과정 중복 | 원칙 1강좌, 70% 이상 다른 과정임 증명 시 2강좌 인정 |
| 학기 중 기간 중복 (원격+원격 또는 원격+집합) | 짧은 연수 기간의 1/4 이하인 경우 2강좌 인정 |
| 방학 중 기간 중복 | 2강좌 모두 인정 |
| 집합연수 2개 이상 동시 수강 | 물리적으로 불가 → **불인정** |
| 긴급정책연수·휴업일 연수 중복 | 2강좌 인정 |
| 2013.12.31. 이전 연수 | 기간 중복 금지 기준 적용 |
| 2014.1.1. 이후 개설 연수 | 기간 중복 금지 폐지 |
