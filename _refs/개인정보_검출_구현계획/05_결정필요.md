|---|---|---|
| 1 | 댓글에서 실명 추정 | **경고 후 등록 허용** |
| 2 | 직위만 언급("교감 선생님이 …") | **경고 후 등록 허용** |
| 3 | 신고 기능 | **개발. 서로 다른 신고자 5명 이상이면 자동 숨김** |
| 4 | 실제 NEIS 파일 구성(인적사항 포함 여부) | 실제 파일은 나중에 받기로 함 — **현재 `_refs` 예시 파일 기준으로 개발** |

| 6 | 잘못된 파일 차단 기준 | 인사기록카드 구획이 하나도 없고 차단 등급 개인정보 **5건 이상** |
| 7 | 범위 | **신고까지 전부 개발** |
